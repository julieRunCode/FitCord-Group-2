### Description
Fitcord relies on a two-prong approach to implementing its vision. Because of this, development is split along two primary directories - Bot Development and Mobile App Development.
Both sides of this platform tie to the same shared DB so information is universal across the divide.

### Mobile App 
This sub-directory facilitates the development of the Mobile App. Here, the logic will be developed for:
- Account registration
- Mobile app UI
- Tracking and updating workouts
- Retrieving challenges from your joined communities
- Community map discovery
- And more

### Proposed Development Notes
- Utilize React Native for Mobile App and ease of modern development
